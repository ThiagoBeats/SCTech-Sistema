## Design
- **Base de instituições `js/bancos-base.js`** (gerada agora a partir de `https://brasilapi.com.br/api/banks/v1`, guardada no repositório para funcionar sem internet): `BANCOS_BASE = [{ ispb, codigo: '001'|null, nome (curto), nomeCompleto }]` ordenada por nome; script `tools/atualizar-bancos.js` (node) regenera o arquivo. **Atualização em uso:** com internet, uma vez a cada 30 dias o sistema busca a BrasilAPI e guarda em `localStorage.sc_bancos_cache` `{ em, lista }`; a busca usa cache (se mais novo) senão a base do arquivo; falha de rede não mostra erro.
- **Logos:** pasta `img/bancos/` com SVG/PNG das ~60 instituições mais usadas (chave = código COMPE, ou ISPB quando não há código), mapeadas em `js/bancos-base.js` (`BANCOS_LOGOS = { '001': 'img/bancos/001.svg', … }`). Fonte: repositório público de logos de bancos brasileiros com licença que permita redistribuição (verificar e registrar a licença em `img/bancos/LEIAME.txt`). Se nenhuma fonte tiver licença clara, não copiar arquivos: usar as URLs do CDN (jsDelivr) do repositório em tempo de execução, e sem internet cair no selo. Sem logo → selo atual (sigla + cor, `FIN_BANCOS` continua para as cores dos principais; demais: iniciais do nome e cor neutra).
- **Núcleo puro `js/bancos-core.js`** (UMD, global `BancosCore`):
  - `buscar(lista, termo, limite=8) -> [{ispb, codigo, nome, nomeCompleto}]` — sem acento/caixa; casa por código exato primeiro, depois início do nome, depois palavra do nome/nome completo; ordem estável; termo vazio → [].
  - `formatoDoBanco(codigo) -> { agencia: { digitos, dv: bool }, conta: { digitos, dv: bool, operacao?: digitos } }` — tabela para: 001 BB (ag 4+DV, conta 8+DV, DV pode ser X), 104 Caixa (ag 4, conta com operação 3 ou 4 dígitos + 8 + DV), 237 Bradesco (ag 4+DV, conta 7+DV, DV pode ser P), 341 Itaú (ag 4, conta 5+DV), 033 Santander (ag 4, conta 8+DV), 260 Nubank (ag 4 "0001", conta 7–10+DV), 077 Inter (ag 4, conta 9+DV), 336 C6 (ag 4, conta 8+DV), 756 Sicoob (ag 4, conta até 10+DV), 748 Sicredi (ag 4, conta 5–6+DV), 290 PagBank (ag 4, conta 8+DV), 323 Mercado Pago (ag 4, conta 10+DV), 212 Original, 655 Votorantim/Neon, 380 PicPay, 403 Cora, 197 Stone, 422 Safra, 041 Banrisul, 070 BRB, 004 BNB, 021 Banestes (usar formatos conhecidos; quando houver dúvida, genérico); genérico: agência até 4 dígitos + DV opcional, conta até 12 + DV.
  - `mascararAgencia(texto, codigo) -> string` e `mascararConta(texto, codigo) -> string` — aceitam dígitos e o DV (incluindo X/P), põem "-" antes do DV; Caixa: "0013 00012345-6" (operação + conta). Nunca perdem dígitos digitados (excedente fica, para não apagar dado antigo).
- **Tela (Configurar Empresa › contas, `js/app.js` ~930):** o `<select class="conta-banco-sel">` vira um campo de busca no **mesmo lugar e tamanho**: input com a logo à esquerda (quando escolhido) + lista suspensa (logo, nome, código) com setas/Enter/Esc e clique; grava `banco` = código COMPE (ou `ispb:<ISPB>` quando não há código) e `banco_nome`; contas antigas continuam mostrando o banco já salvo. Agência/conta: máscara do banco escolhido enquanto digita (`BancosCore.mascararAgencia/Conta`), refeita ao trocar de banco; `data-sem-maiuscula`. Resumo do Financeiro (`js/fin-novo.js` ~35, `.res-selo`): mostra a logo quando houver, senão o selo.
- **Fluxo › Ver por:** os três botões (Dia, Semana, Mês) com a mesma largura, suficiente para "Semana" e "Mês" sem corte (min-width igual + padding lateral maior), só nesse grupo; nada mais muda.
